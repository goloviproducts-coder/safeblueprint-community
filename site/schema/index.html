Report schema

Version 1.1 of the SafeBlueprint report file. Version 1.0 files still load. Your browser builds the file. This site does not store it.

safeblueprint-report.schema.json

Draft 2020-12. The current schema id is https://safeblueprint.pages.dev/schema/report/v1.1.json. It accepts a 1.0 file and adds an optional portfolio block.

Open the schema file. The previous file remains at /schema/report/v1.json.

A report file can be loaded again on the ADM inventory page after a refresh. Loading it does not send the file anywhere.
