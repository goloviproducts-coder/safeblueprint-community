# Security Policy

Please **do not** open public issues for vulnerabilities.

Report privately via GitHub: **Security tab -> Report a vulnerability** (private vulnerability reporting / Security Advisories):
https://github.com/goloviproducts-coder/safeblueprint-community/security/advisories/new

Include affected version (`VERSION`), steps to reproduce and impact. Supported: latest release only.

## Our promise
- **Acknowledge within 72 hours** of your report.
- Give you an initial assessment and planned next steps within 7 days.
- Keep you updated until the issue is resolved, and credit you in the advisory if you wish.

## How we publish advisories
1. We confirm the issue privately in a draft GitHub Security Advisory and, where it qualifies, request a CVE through GitHub.
2. We fix it in a private fork, run every required check, and release a patched version.
3. We publish the advisory on the [Security Advisories page](https://github.com/goloviproducts-coder/safeblueprint-community/security/advisories) with the affected versions, the fix and any workaround, and note it in the CHANGELOG under Security fixes.
4. Dependabot alerts reach downstream users automatically through the GitHub Advisory Database.
