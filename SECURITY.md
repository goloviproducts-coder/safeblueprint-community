# Security Policy

Please **do not** open public issues for vulnerabilities.

Report privately via GitHub: **Security tab -> Report a vulnerability** (private vulnerability reporting / Security Advisories):
https://github.com/goloviproducts-coder/safeblueprint-community/security/advisories/new

Include affected version (`VERSION`), steps to reproduce and impact. We aim to acknowledge within 5 business days. Supported: latest release only.
